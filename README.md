# Xiazhouqi TikTok & Douyin Cover Skill

下周七自用的 TikTok / 抖音科技教程封面设计 Skill。

## 用法

在一个全新的 ChatGPT 对话中同时提供：

1. `SKILL.md`
2. `REFERENCE_CANONICAL.webp`
3. 本期封面的主题与必要文案

然后直接要求：

> 按这个 Skill 和参考母版，制作本期 TikTok / 抖音科技封面。保持下周七视觉 DNA，但根据主题重新组织版式。

## 固定视觉 DNA

- 3:4 竖版
- 极窄黑色分隔缝
- 奶油香槟金实体金属边框
- 奶杏 / 暖白低饱和背景
- 克制的品牌色
- 单一主视觉 + 少量毛玻璃信息卡
- 同一品牌，不同版式

## 文件

- `SKILL.md`：完整执行规范
- `REFERENCE_CANONICAL.webp`：唯一视觉母版
