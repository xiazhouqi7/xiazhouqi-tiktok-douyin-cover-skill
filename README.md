# Xiazhouqi TikTok & Douyin Cover Skill

下周七自用的 TikTok / 抖音科技教程封面设计 Skill。

## 用法

在一个全新的 ChatGPT 对话中同时提供：

1. `SKILL.md`
2. `REFERENCE_CANONICAL.webp`
3. `REFERENCE_ASPECT_ONLY.webp`（只用于确认画布比例，不能用作风格参考）
4. 本期封面的主题与必要文案

然后直接要求：

> 按这个 Skill 和参考母版，制作本期 TikTok / 抖音科技封面。保持下周七视觉 DNA，但根据主题重新组织版式。

## 独立尺寸参考（只看比例）

![抖音封面 3:4 尺寸参考](REFERENCE_ASPECT_ONLY.webp)

- **源图实际尺寸：1086 × 1448 px，严格 3:4。** 仓库中保存的是等比例缩小的 **120 × 160 px WebP 预览**，仅用于查看画布的长宽关系。
- **只参考图片比例、画布外形和纵横尺寸关系。** 不参考该图的颜色、字体、排版、金色光效、人物 / 机器人、电脑、文案或细节。
- 这张图**不是**新的视觉母版。`REFERENCE_CANONICAL.webp` 仍是唯一的风格母版。
- 抖音独立封面按 **3:4** 制作；**9:16 是视频画面比例，不要拿它当独立封面比例。**

## 固定视觉 DNA

- 3:4 竖版
- 极窄黑色分隔缝
- 奶油香槟金实体金属边框
- 奶杏 / 暖白低饱和背景
- 克制的品牌色
- 单一主视觉 + 少量毛玻璃信息卡
- 同一品牌，不同版式

## 文件

- `SKILL.md`：完整执行规范
- `REFERENCE_CANONICAL.webp`：唯一视觉母版（风格）
- `REFERENCE_ASPECT_ONLY.webp`：用户指定的 3:4 比例参考图（原图的轻量预览，仅尺寸）
